GAVRIELLA'S BIRTHDAY WEBSITE
============================

FILES
- index.html: page structure
- style.css: dark gothic / forest-green styling
- script.js: countdown, gallery, letter animation, optional music

PREVIEW
1. Keep all three files in the same folder.
2. Double-click index.html, or open it in a browser.
3. The lock screen counts down to November 13, 2026 at 9:00 PM WIB.
4. After unlock, use “Add pictures” to add character images.
5. Click the envelope to reveal the letter.
6. Click the music control and choose an audio file from your device.

PERSONALIZE THE LETTER
Open script.js only if you want to change the letter text: edit the three paragraphs inside
the <article id="letterContent"> element in index.html.

IMPORTANT NOTES
- The countdown uses the fixed WIB target time (UTC+7), regardless of the viewer's timezone.
- This is a front-end surprise gate, not secure access control. Someone technical could bypass it.
- Gallery pictures and captions are stored in the browser's local storage on the device where they are added.
  They are not automatically shared with Gavriella. For a shared public gallery, upload the site and its
  images to a hosting service and add image files to the site itself.
- Music is optional and selected locally by the visitor; browsers do not allow reliable autoplay.
- Google Fonts are loaded online. The page still works offline with fallback fonts.
